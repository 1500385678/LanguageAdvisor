## 一、项目概述

### 1.1 愿景

> **让每个学习者身边都有一位"北外教授 + 一位母语者 + 一位语言学家"。**

把张勇已经整理的"汉语 → 英语 → 二外（法/德/日/西/俄）→ 语言学理论 → 翻译 → 跨文化交际"完整知识图谱，做成一个**会思考的语言顾问**——能教语法、能练听说、能讲文化、能改作文，也能针对一段文字给出"准确 + 得体 + 文化"三件套。

### 1.2 形态

| 形态 | 场景 | 状态 |
|------|------|------|
| **飞书 Agent（当前）** | 工作中随问随答 | ✅ 已上线 |
| **Web App（核心）** | 自学/考级/教师 | ⏳ 规划中 |
| **桌面端（Electron/Tauri）** | 写作场景 | 📋 远期 |
| **微信小程序** | 启蒙/家长 | 📋 远期 |
| **REST API** | 嵌入词典/翻译工具 | 📋 远期 |
| **浏览器插件** | 读网页时实时学 | 📋 远期 |

### 1.3 已有资产盘点

| 资产 | 位置 | 价值 |
|------|------|------|
| 汉语图谱 | `chinese_knowledge.md` | 语音/汉字/词汇/语法/修辞 |

## 二、产品定位

### 2.1 目标用户

| 用户群 | 痛点 | 价值 |
|--------|------|------|
| **儿童启蒙** | 抽象、坐不住 | 互动游戏 + 动画 |
| **中学生** | 死记硬背、哑巴英语 | 情境对话 + 听力训练 |
| **大学生（四六级/雅思/托福）** | 应试训练、写作弱 | 系统化训练 + 作文批改 |
| **语言专业学生** | 知识碎片化、缺文化 | 跨文化桥接 + 翻译训练 |
| **翻译从业者** | 术语、口吻难统一 | 术语库 + 风格迁移 |
| **跨文化工作者** | 礼仪差异、误读 | 文化案例库 + 情景模拟 |

### 2.2 核心价值主张

1. **语言三件套讲解**：选知识点 → 同时输出"准确 + 得体 + 文化"
2. **AI 听说训练**：对话 + 发音 + 听力 多模态训练
3. **AI 作文批改**：上传作文 → 语法 + 词汇 + 风格 + 文化 全方位批改
4. **文化情境模拟**：商务/学术/日常/旅游 场景对话
5. **跨语言桥接**：中英对照 + 文化差异 + 直译陷阱
6. **翻译辅助**：术语库 + 风格迁移 + 校对

### 2.3 差异化（vs 现有产品）

- **多邻国 / 扇贝**：练习型，缺文化深度、缺学术严谨
- **有道 / 百度翻译**：翻译型，缺教学闭环
- **Cambly / italki**：真人外教，贵、不可规模化
- **Grammarly**：英文写作好，无中文对齐
- **学堂在线 / 中国大学MOOC**：录播型，互动性弱

**我们的差异**：以张勇的**结构化知识图谱 + 文化背景库**为骨架，AI 提供"准确 + 得体 + 文化"三件套，覆盖中英双主 + 多二外 + 语言学 + 翻译 + 跨文化全链路。

### 3.1 五大核心模块

### 3.2 模块拆分

#### 模块 1：知识图谱（Knowledge Graph）
- **数据结构**：节点（知识点）+ 边（前置 / 衍生 / 跨语言关联）
- **覆盖**：汉语 → 英语 → 二外 → 语言学 → 翻译 → 跨文化
- **节点属性**：
  - name, language, level, difficulty, tags, prerequisites
  - texts[]（相关课文）
  - dialogues[]（相关对话）
  - culture[]（关联文化点）
  - translations[]（关联翻译案例）
  - cross_lang[]（跨语言对照）
  - explanation[]（三件套讲解：准确/得体/文化）

#### 模块 2：训练场（Training Ground）
- **听力训练**：
  - 分级听力材料（教材/VOA/BBC/CRI）
  - 变速播放 + 听写模式
  - 关键词捕捉 + 全文理解
- **口语训练**：
  - 跟读评分（语音识别 + 发音评估）
  - 情境对话（商务/学术/日常/旅游）
  - 影子跟读训练
- **阅读训练**：
  - 分级阅读材料
  - 长难句解析
  - 文化注释
- **写作训练**：
  - 模板写作（雅思/托福/学术/商务）
  - AI 反馈 + 修改建议
  - 优秀范文库

#### 模块 3：批改工具（Essay Check & Translation Aid）
- **作文批改**：
  - 语法错误（拼写/时态/搭配/句式）
  - 词汇优化（同义替换、学术化、得体化）
  - 风格诊断（正式/非正式、简洁/冗长）
  - 文化贴切度
  - 综合评分 + 改进建议
- **翻译辅助**：
  - 术语库匹配
  - 风格迁移（直译/意译/归化/异化）
  - 校对（漏译/错译/语句不顺）
  - 多版本输出（直译版/意译版/创译版）

#### 模块 4：智能讲解（AI Tutor）
- **三件套讲解**：选知识点 → 同时输出"准确 + 得体 + 文化"
- **多语言支持**：中/英/法/德/日/西/俄
- **情境对话**：扮演对话伙伴（外教/客户/同事）
- **跨语言问答**："这个英文词在中文里怎么最贴切？" → 多版本 + 文化差异
- **语法难点**：英文虚拟语气、中文把字句、文化敬语

#### 模块 5：多端 UI
- Web App（核心）：响应式设计，PC / 平板 / 手机
- 飞书机器人：消息形态（当前）
- 小程序：听说训练轻量版
- 桌面端：写作 + 翻译深度场景
- 浏览器插件（远期）：读网页时实时学

### 4.2 技术栈选型

| 层 | 选型 | 理由 |
|----|------|------|
| **后端框架** | FastAPI（Python） | 异步、自动文档、NLP 生态 |
| **前端** | React + TypeScript | 组件丰富 |
| **UI 库** | Ant Design / shadcn/ui | 中文友好 / 现代 |
| **NLP 工具** | jieba / HanLP / spaCy | 中文分词、命名实体、句法 |
| **语音识别** | Whisper (OpenAI) / Paraformer | 多语言 ASR |
| **发音评估** | Wenet / 自研 | 音素级评分 |
| **TTS** | GPT-SoVITS / Edge TTS | 多语言合成 |
| **词典数据** | ECDICT / CC-CEDICT | 开源中英词典 |
| **数据库** | PostgreSQL（主） + SQLite（离线） | 张勇已有 SQLite 经验 |
| **缓存** | Redis | 词典缓存、AI 响应缓存 |
| **向量库** | pgvector / Chroma | 跨语言检索、相似作文 |
| **LLM** | Claude / GPT / 本地 Ollama | 讲解 / 批改 / 翻译 |
| **部署** | Docker Compose → K8s | 单机起步，平滑扩容 |
| **CI/CD** | GitHub Actions | 自动化 |
| **监控** | Sentry + Prometheus | 错误 + 性能 |
| **认证** | JWT + 飞书 OAuth | 飞书用户无缝 |

### 4.3 数据架构

#### 核心表

```sql
-- 知识点表
CREATE TABLE knowledge_points (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  language TEXT,                -- zh/en/fr/de/jp/es/ru
  level TEXT,                   -- 启蒙/初级/中级/高级/母语
  difficulty INT,               -- 1-5
  description TEXT,
  texts JSONB,                  -- 关联课文
  dialogues JSONB,              -- 关联对话
  culture JSONB,                -- 关联文化点
  translations JSONB,           -- 关联翻译
  cross_lang JSONB,             -- 跨语言对照
  explanation JSONB,            -- 三件套讲解
  prerequisites INT[],
  tags TEXT[]
);

-- 课文库
CREATE TABLE texts (
  id SERIAL PRIMARY KEY,
  title TEXT,
  language TEXT,
  level INT,
  genre TEXT,                   -- 教材/文学/新闻/学术
  content TEXT,
  audio_url TEXT,
  annotations JSONB,            -- 注释
  comprehension_questions JSONB,
  knowledge_ids INT[]
);

-- 听力材料
CREATE TABLE audio_lessons (
  id SERIAL PRIMARY KEY,
  title TEXT,
  language TEXT,
  level INT,
  duration INT,
  audio_url TEXT,
  transcript TEXT,
  vocabulary JSONB,
  comprehension_questions JSONB,
  knowledge_ids INT[]
);

-- 语法题库
CREATE TABLE grammar_questions (
  id SERIAL PRIMARY KEY,
  language TEXT,
  level INT,
  type TEXT,                    -- choice/fill/error_correction
  question TEXT,
  options JSONB,
  answer TEXT,
  analysis TEXT,
  knowledge_id INT
);

-- 词条
CREATE TABLE words (
  id SERIAL PRIMARY KEY,
  word TEXT,
  language TEXT,
  pos TEXT,                     -- 词性
  pronunciation TEXT,           -- IPA
  definitions JSONB,
  examples JSONB,
  collocations JSONB,
  etymology TEXT,
  frequency INT,
  tags TEXT[]
);
CREATE INDEX idx_words_word_lang ON words (word, language);

-- 文化背景
CREATE TABLE culture_items (
  id SERIAL PRIMARY KEY,
  title TEXT,
  language TEXT,
  category TEXT,                -- 历史/礼仪/饮食/节日/价值观
  description TEXT,
  examples JSONB,
  cross_culture_notes TEXT,
  knowledge_ids INT[]
);

-- 作文批改
CREATE TABLE essay_reviews (
  id SERIAL PRIMARY KEY,
  user_id INT,
  original_text TEXT,
  language TEXT,
  issues JSONB,                 -- 错误列表
  suggestions JSONB,
  revised_text TEXT,
  score JSONB,
  reviewed_at TIMESTAMP
);

-- 翻译案例
CREATE TABLE translation_cases (
  id SERIAL PRIMARY KEY,
  source_text TEXT,
  source_lang TEXT,
  target_lang TEXT,
  versions JSONB,               -- 直译/意译/创译
  terminology JSONB,
  notes TEXT,
  knowledge_ids INT[]
);

-- 用户表
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  open_id TEXT UNIQUE,
  name TEXT,
  native_lang TEXT,
  target_langs JSONB,
  level JSONB,                  -- 各语言水平
  created_at TIMESTAMP
);

-- 学习进度
CREATE TABLE user_progress (
  user_id INT,
  knowledge_id INT,
  mastery REAL,
  attempts INT,
  correct INT,
  last_seen TIMESTAMP,
  PRIMARY KEY (user_id, knowledge_id)
);
```

#### 已有 SQLite 表（迁移）

- 写迁移脚本 → PostgreSQL
