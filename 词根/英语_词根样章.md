## 看 · 词族(17 词根)

英语 "看" 词族源自拉丁 vid/vis(spec 来自 specere,spect 来自 spectare),本族贡献 70%+ "观看/视觉" 词汇。

### vid

- 词源: 拉丁 videre
- 本义: 看
- 难度: 2 (A2-B1)
- 派生: evident(adj 明显的, ex-外 + vid → 看得见的), provide(v 提供, pro-前 + vid → 摆在前面看), video(n 视频, 直接保留), vision(n 视觉/愿景, -ion 名词后缀), visual(adj 视觉的, -ual 形容词后缀), revise(v 修订, re-再 + vis → 再看一遍), supervise(v 监督, super-上 + vis → 在上看), television(n 电视, tele-远 + vis + ion → 远距离看的画面)
- 例句: The evidence is evident from the video. / I need to revise my plan.
- 标签: 词族-看, 词族-动词族, 词族-名词族, 高考, 四级, 雅思

### vis

- 例句: The stars are visible on a clear night. / I advise you to wait.
